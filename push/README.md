# שרת ההתראות

שרת קטן ב-Cloudflare Workers (בחינם) ששולח את התזכורות של האפליקציה כהתראות Web Push, בזמן שלהן, גם כשהאפליקציה סגורה.

**מה מגיע לשרת:** רק רשימת התזכורות של כל מכשיר (זמן, כותרת, שורה קצרה) והכתובת שהדפדפן נותן לשליחת התראות. אין כאן טוקן של Moodle ואין גישה לחשבון. כל תזכורת נמחקת אחרי שנשלחה, ומכשיר שלא נפתח חודשיים נשכח.

**איך זה בנוי:** Durable Object לכל מכשיר שומר את התזכורות שלו ומעיר את עצמו (alarm) בדיוק בזמן הבאה. מפתח ה-VAPID נוצר בשרת בפעם הראשונה ולא יוצא ממנו.

| כתובת | מה עושה |
|---|---|
| `GET /key` | המפתח הציבורי של השרת, בשביל ההרשמה להתראות |
| `POST /sync` | `{sub, items:[{at, title, body, tag}], lang}`: מחליף את רשימת התזכורות של המכשיר |
| `POST /unsub` | `{endpoint}`: שוכח את המכשיר |
| `POST /test` | `{endpoint, title, body}`: התראה אחת עכשיו |

**העלאה:** אוטומטית מ-GitHub Actions (`.github/workflows/push-worker.yml`) בכל שינוי בתיקייה. צריך Secret אחד, `CLOUDFLARE_API_TOKEN`; מספר החשבון כתוב ב-`wrangler.toml`. הכתובת של השרת, או השגיאה, מופיעה כהודעה בסיכום הריצה. אחרי ההעלאה הראשונה הכתובת `https://moodle-task-push.<subdomain>.workers.dev` נכנסת ל-`PUSH_URL` ב-`index.html`.
